# .task — 작업 기록 / 진행 관리

이 프로젝트에서 Claude와 진행하는 작업의 **현황·히스토리·향후 계획**을 기록/관리한다.
(CLAUDE.md 의 "작업 기록(필수)" 규칙과 연동)

## 구성
- **`WORKLOG.md`** — 시간순 작업 히스토리(최신이 위). 의미 있는 작업/커밋을 마치면 맨 위에 항목 추가.
- **`BACKLOG.md`** — 미구현 기능 / 향후 계획. 새 과제가 생기면 추가.
- **`NNN-제목.md`** — (선택) 착수한 개별 작업의 상세 계획. 완료되면 `WORKLOG.md` 에 한 줄 남기고 정리.

## 흐름
1. 작업 시작 전 `WORKLOG.md`(최근 한 일)와 `BACKLOG.md`(할 일)를 확인한다.
2. 큰 작업이면 `NNN-제목.md` 로 계획을 잡는다.
3. 작업/커밋을 마치면 `WORKLOG.md` 맨 위에 `날짜 · 한 일 · 관련 커밋` 을 기록한다.
4. 도중에 발견한 향후 과제는 `BACKLOG.md` 에 적는다.

## 개별 작업 계획 템플릿 (`NNN-제목.md`)

```markdown
# <작업 제목>

- 상태: 진행중 | 대기 | 완료
- 관련 파일: src/...

## 배경 / 목적

## 작업 내용
- [ ] 단계 1
- [ ] 단계 2

## 메모 / 결정 사항
```
