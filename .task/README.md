# .task — 작업 계획 폴더

진행 중이거나 예정된 작업의 **계획·메모**를 담는다. 코드가 아닌, "무엇을 왜 어떻게 할지"의 기록.

## 사용 규칙

- 파일명: `NNN-짧은-제목.md` (예: `001-jsp-source-marker.md`). 번호로 생성 순서를 유지.
- 한 파일 = 한 작업 단위. 완료되면 상단에 `상태: 완료` 표기(삭제하지 않고 이력으로 남김).
- 작은 메모는 이 폴더의 `notes.md` 에 모아도 무방.

## 권장 템플릿

```markdown
# <작업 제목>

- 상태: 진행중 | 대기 | 완료
- 관련 파일: src/...

## 배경 / 목적

## 작업 내용

- [ ] 단계 1
- [ ] 단계 2

## 메모 / 결정 사항
```

## 백로그 (CLAUDE.md 미구현 항목과 연동)

- JSP 파일 표식(meta/data 속성, dev 프로필 한정)
- COMMON_PATTERNS 를 UniFLOW 디렉터리 구조에 맞게 커스터마이즈
- 녹화 데이터 → 자연어 변환(Claude API 후처리)
- `data-main` 속성 마킹(메인 JS 특정)
