    스프레드시트 ID
    저장할 Google Sheets URL에서 ID를 복사하세요.
    docs.google.com/spreadsheets/d/[여기]
    서비스 계정 JSON
    Google Cloud Console에서 발급한 서비스 계정 JSON 파일의
    내용을 붙여넣으세요.
    사용 방법
    1. Google Cloud Console → 서비스 계정 생성
    2. 키 추가 → JSON 다운로드
    3. JSON 파일 내용을 위 입력란에 붙여넣기
    4. 저장할 Google 스프레드시트를
      서비스 계정 이메일(client_email)에 편집자 공유
    5. 녹화 탭에서 스프레드시트 ID 입력 후 저장
